# FormLab — конструктор опросов

Небольшой учебный проект на React + TypeScript. Интерфейс на русском языке, адаптирован для телефона.


Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Демо-вход

- Email: `hello@formlab.ru`
- Пароль: `123456`


## Что сделано

- Вход и регистрация с проверкой полей.
- Список опросов: поиск с задержкой, фильтр статуса, сортировка, URL-параметры.
- Создание, удаление и дублирование опросов.
- Редактор восьми типов вопросов, варианты ответов, обязательность, копирование вопросов.
- Перетаскивание вопросов мышью и клавиатурой.
- Автосохранение через небольшую задержку, предупреждение при закрытии с несохранёнными изменениями.
- Публикация, ссылка на опрос и предпросмотр.
- Прохождение опроса, локальный черновик и защита от повторного прохождения в этом браузере.
- Результаты с диаграммами, просмотр отдельных ответов и CSV-экспорт с поддержкой кириллицы.
- Адаптивная вёрстка.
